# `reason-from-reality`：让现实修正判断

> 10 秒定义：把长期学习、计划、诊断或不确定性决策变成“目标→现实→差距→行动→测量→复测→更新”的证据闭环。

- [English guide](reason-from-reality.md)
- [执行入口](../../skills/reason-from-reality/SKILL.md)

## 它解决的高代价失败

很多计划听起来完整，却没有回答：目标行为是什么、现实表现如何、主要瓶颈在哪里、下一步如何测量、什么时候根据结果调整。学习中尤其容易把看过当成会做，把即时重做当成掌握，把一次好表现当成稳定能力。

这个 Skill 还防止另一种错误：把“文明级智慧内核”写成思想家名录、神秘权威或鼓励话术。它要求跨传统原则先被翻译成可观察行为、测量、试验和边界，再接受现实、逻辑、实践、结果和复测的检验。

## 何时使用 / 何时不要使用

### 使用它

- 长期备考、学习系统和能力形成；
- 根据真实练习记录诊断瓶颈；
- 计划评估、习惯或流程改进；
- 复盘旧报告与新证据的冲突；
- 需要明确不确定性、行动实验和更新规则的决策。

### 不要使用它

- 一次性事实问答；
- 翻译、改写、起标题；
- 简单语法修复；
- 没有测量、复测或更新需求的普通建议。

医疗、法律、危机、重大财务、就业、升学或人身安全问题不能被当作普通优化任务；先阅读安全边界并转向适当的专业或官方来源。

## 文明级智慧内核：操作性定义

“文明级”表示跨传统提炼可复用的共同原则，不表示无所不知，也不把任何时代、国家、学派、思想家或作者当作最终权威。

“智慧内核”表示把原则压缩成：

```text
原则 → 可观察行为 → 测量 → 小实验 → 边界 → 更新规则
```

现实、逻辑、实践、结果和复测拥有最终裁决权。旧 AI 报告是待审计的判断，不是新事实来源。证据不足就写 `UNKNOWN`，不补造确定性。AI 可以解释、出题、检查和调度，但不能在目标是能力形成时替代用户自己的提取、推导、写作、做题或编程。

## 核心循环

```text
目标 → 现实 → 差距 → 主要矛盾 → 行动
→ 测量 → 迁移/延迟复测 → 更新
```

### 1. 定义目标行为

把“掌握”“更自律”“提高能力”翻译成带条件、时间窗和成功标准的可观察行为：

```text
目标：30 分钟内闭卷独立完成陌生变式题，并解释关键步骤
指标：首次正确率、完成时间、错误类型、第 3 天延迟保持率
窗口：未来 7 天，第 1、3、7 天复测
```

### 2. 建立证据账本

把每个重要说法分成：

- **事实：** 直接观察和条件；
- **判断：** 对事实的解释与置信度；
- **行动：** 一个可执行干预；
- **验证：** 能够改变判断的测试；
- **未知：** 缺失但重要的事实。

自我感受、信心和意愿可以提供上下文，但不能代替代表性表现。

### 3. 诊断第一瓶颈

区分暴露、理解、检索、程序、迁移、保持、环境和能量/动机。不要用一个分数或一次状态推断稳定特质，也不要在瓶颈未知时先堆一个完整日程。

### 4. 选择小行动或实验

选一个主要变量，写清行为、条件、时长、数据记录和停止/切换规则。行动的价值由它能否减少不确定性或改善目标表现决定，而不是由看起来忙不忙决定。

### 5. 即时、迁移和延迟复测

学习中的层次不能互换：

```text
接触 → 解释 → 无提示提取 → 程序执行
→ 变换题面迁移 → 延迟保持
```

即时看解析后的重做只能证明部分表现；至少在相近但不相同的任务和合适延迟后复测。

### 6. 更新、切换或停止

- 若目标在即时和延迟/迁移测试中改善，保留方法并逐步变化题面；
- 若只有即时表现改善，减少识别线索，增加无提示提取和迁移；
- 若有界试验后指标不动，重新检查瓶颈或只更换一个主要变量；
- 若风险或不确定性超过证据，停止普通优化并转向适当来源。

## 输入与输出

### 需要的输入

- 真实目标和目标行为；
- 练习/工作记录、任务条件和时间；
- 当前表现、错误模式、过程痕迹和自我报告；
- 可接受的资源、时间窗和风险边界；
- 复测日期与判定规则。

### 输出格式

```text
目标结果：
事实与条件：
主要判断 + 置信度：
瓶颈 / 竞争解释：
下一项行动或实验：
测量 + 复测日期：
更新 / 切换规则：
未知与限制：
```

## 完整匿名案例

一名学习者说“看懂了解析，但遇到陌生题面就不会”。记录显示：最近四次闭卷正确率 55%–65%，看解析后即时重做 90%。

普通处理方式可能是继续看更多讲解、增加题量或用鼓励掩盖不确定性。使用本 Skill 后：

1. 将“看懂”与独立表现分开；
2. 判断检索/迁移不稳比“完全没理解”更符合现有证据，但保留中等置信度；
3. 设计陌生变式题、禁止看笔记、先写解题计划的短实验；
4. 在第 1、3、7 天用相近难度但不同表面的任务复测；
5. 若延迟迁移上升，逐步扩大题面变化；若只在熟悉题面改善，切换到概念边界和步骤错误诊断。

这些数字是匿名示例条件，不是普遍阈值或效果承诺。

## 普通处理方式 vs 使用本 Skill

| 普通处理方式 | 使用本 Skill |
| --- | --- |
| 以“我感觉会了”作为掌握证据 | 区分信心、即时表现、迁移和延迟保持 |
| 先生成完整计划 | 先做小基线，找第一瓶颈 |
| 一次加入很多方法 | 在可归因时一次改变一个主要变量 |
| 把旧 AI 报告当事实 | 保留冲突，和新表现一起审计 |
| 用鼓励消除不确定性 | 标记 `UNKNOWN` 并给出下一项判别测量 |

## 三个可复制提示词

### 提示词 1：学习诊断

> 请根据我的真实闭卷练习记录，区分暴露、理解、检索、程序、迁移和延迟保持。输出事实、判断、行动、验证和未知，并设计一个小实验，而不是先给完整日程。

### 提示词 2：冲突证据

> 旧 AI 报告说我的问题是概念缺失，但最近的独立练习记录不一致。请保留冲突，列出竞争解释和能区分它们的最小复测，不要选择更好听的结论。

### 提示词 3：知行转译

> 把“知行合一”转译为可观察行为、指标、试验、边界、复测日期和更新规则；明确哪些仍是未知，不要用名言替代证据。

## 典型输出片段

```text
目标结果：30 分钟内独立完成陌生变式题，并在第 3 天保持
事实与条件：4 次闭卷 55%–65%；看解析后即时重做 90%
主要判断 + 置信度：更像检索/迁移不稳；中等
下一项行动或实验：做陌生题面，禁止看笔记，记录错误类型和时间
复测：第 1、3、7 天换题面复测
更新：若延迟迁移不上升，转查概念边界与步骤错误
未知：时间压力是否是主要瓶颈
```

## 边界、反模式和失败条件

- 不要把历史原则写成不可质疑的权威；
- 不要发明引文、研究结果或确定性阈值；
- 不要把一次好表现、信心或自我报告变成稳定特质；
- 不要让 AI 代替目标能力的实际形成；
- 不要索要不必要的私密记录；
- 不要在医疗、法律、危机和其他高风险边界内继续普通优化；
- 不要把 `unknown` 填成“可能没问题”。

## FAQ

### 为什么不直接给一份学习计划？

因为没有目标行为、条件、基线和瓶颈时，计划只是外观完整的假设。先做最小证据收集。

### “文明级”是不是夸大？

如果它被当成万能知识库就是夸大。本 Skill 的定义相反：跨传统原则必须被操作化、测量、检验，证据不足就标未知。

### AI 能不能替我学习？

AI 可以解释、生成练习、反馈和调度，但如果目标是你自己的能力，关键提取、推导、写作、做题或编程仍要由你完成。

### 什么情况下应该停止普通优化？

当涉及医疗、法律、危机、重大财务、就业、升学或人身安全，或证据不足以支持继续行动时，应转向适当的专业/官方来源。
