# Changelog

All notable changes to this project are documented here.

## [0.2.0] - 2026-08-21

### Fixed

- Corrected the interpretation of low-interaction execution: it now reduces mandatory user input without reducing user awareness.
- Added non-blocking `CHECKPOINT` updates, real `GATE` semantics, bounded heartbeat guidance, status-on-request rules, and main-thread subagent batch summaries.
### Added

- Chinese default homepage with a parallel, complete English README and preserved compatibility entry.
- Quiet blue-gray Hero, dark/light Hero variants, Social Preview, refreshed banner, and a shared icon family for the three Skills.
- Six bilingual user guides covering triggers, non-triggers, inputs, outputs, cases, boundaries, composition, and FAQs.
- Progressive references for scenario tracing, workpack lifecycle and authorization, verification/retry handling, civilization-core principles, learning transfer, safety boundaries, and evidence strength.
- Honest composition fixtures for cross-layer debugging, long-term learning execution, and simple-task non-loading boundaries.

### Changed

- Tightened the three Skill entrypoints and aligned descriptions, references, and Codex UI metadata.
- Added deterministic validation for links, escaped newline leakage, placeholders, privacy markers, image dimensions, metadata, and bilingual guide coverage.
- Clarified that low interaction does not expand authorization and that source, tests, build, preview, upload, release, and user acceptance prove separate layers.

## [0.1.2] - 2026-08-21

### Added

- Recorded qualitative forward-test evidence for `reason-from-reality`, including learning, noisy-evidence, and professional-boundary scenarios.

## [0.1.1] - 2026-08-21

### Fixed

- Expanded trigger fixtures so both positive and near-neighbor negative cases include English and Chinese prompts.

## [0.1.0] - 2026-08-21

### Added

- `trace-feature-chain` for evidence-first end-to-end feature diagnosis.
- `run-autonomous-workpacks` for safe, low-interaction execution across adjacent stages.
- `reason-from-reality` for evidence-grounded learning, planning, assessment, and updating.
- English and Chinese READMEs, public-safe origin notes, deterministic validation, trigger fixtures, rubrics, CI, and contribution/security documents.
