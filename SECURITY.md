# Security Policy

Do not report secrets, tokens, private URLs, real user data, or exploit details in a public issue.

For a suspected security problem, contact the repository maintainers through GitHub's private vulnerability reporting channel if enabled, or open a minimal private contact request without including the sensitive value. Describe the affected file, impact, and safe reproduction boundary. Never paste credentials into an issue or pull request.

This repository contains instructions and static validation only. It has no intended telemetry, credential collection, or production access.
